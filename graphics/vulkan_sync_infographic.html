Two-Step Process

  • Source queue: release barrier (src→dst family index)
  • Semaphore / fence between submissions
  • Dest queue: acquire barrier (same indices)
  • Image layouts transition at acquire side

Notes

  • Via VkBuffer/ImageMemoryBarrier fields
  • CONCURRENT sharing skips this (slower)
  • Both barriers must specify matching indices
